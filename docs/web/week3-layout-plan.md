แผนตำแหน่ง: จอกว้าง ข้างบนสุดฝั่งซ้ายมีชื่อร้านฝั่งขวามีสินค้าและตะกร้าต่อมามีสมุดและปากกาวางข้างกันอยู่ตรงกลางถัดจากนั้นมีformเอาไว้เลือกสนค้าและจำนวนและมีปุ่มส่ง ล่างสุดมี ตะกร้าและfooter

จอแคบ — บนสุดมีชื่อร้านและเมนูลงมามีสมุดอยู่เหนือปากกาและมีformอยู่ข้างใต้และมีตะกร้าและfooterอยู่ส่งนท้าย

เครื่องมือและเหตุผล: ส่วนหัวใช้ Flexbox ให้เมนูขึ้นแถวใหม่ได้; รายการสินค้าใช้ Grid เพื่อกำหนดจำนวนคอลัมน์
