# API รายการสินค้า
สถานะ: PROPOSED
รุ่น: v1
เจ้าของข้อเสนอ: Microservice

คำขอ: GET /api/v1/catalog/products
Request body: ไม่ส่ง
Query: available เลือกใส่ได้ รับ true หรือ false

| id        | ชื่อสินค้า      | priceSatang | available |
|-----------|-----------------|-------------|-----------|
| pencil    | ดินสอ           | 1200        | true      |
| ruler     | ไม้บรรทัด       | 2000        | false     |
| eraser    | ยางลบ           | 800         | true      |
| sharpener | กบเหลาดินสอ     | 1500        | false     |


| Query ที่ส่ง   | Status ที่คาด | Response body ที่คาด                              | เหตุผล                              |
|----------------|---------------|---------------------------------------------------|-------------------------------------|
| available=true | 200           | data มีดินสอและยางลบอย่างละ 1 รายการ              | ดินสอและยางลบมีค่าเป็น true          |
| available=false| 200           | data มีไม้บรรทัดและกบเหลาดินสออย่างละ 1 รายการ    | ไม้บรรทัดและกบเหลาดินสอมีค่าเป็น false |
| available="yes"| 422          | Error                                             | ไม่มีค่าที่ตอบกลับ yes              |
| available      | 200           | data ส่งข้อมูลทุกอันที่มี                         | เพราะไม่ได้ใส่อะไรจึงได้ข้อมูลทุกอย่าง |
